# 📐 Design System v2 Specification (`docs/DESIGN_SYSTEM_V2.md`)

Design tokens, 60/30/10 color rule, and 8-point grid specification.

---

## 1. 60/30/10 Color Rule Tokens
- **60% Base**: `--bg-app: #0f172a` (Dark Slate Workstation)
- **30% Surfaces**: `--bg-surface: #1e293b`, `--text-primary: #f8fafc`, `--border-subtle: #334155`
- **10% Brand Accent**: `--brand-primary: #0284c7`, `--brand-success: #16a34a`

---

## 2. 8-Point Grid System
All margins, paddings, and component heights adhere to multiples of 4px or 8px:
`--space-2: 4px`, `--space-4: 8px`, `--space-6: 12px`, `--space-8: 16px`, `--space-12: 24px`, `--space-16: 32px`, `--space-24: 48px`.

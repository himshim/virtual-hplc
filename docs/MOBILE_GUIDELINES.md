# 📱 Mobile-First UI/UX Guidelines (`docs/MOBILE_GUIDELINES.md`)

Mobile design rules derived from `mobile-app-ui-design` skill.

---

## 1. Key Rules
- **Thumb Zone Layout**: Primary actions (`▶ Run Experiment`, `Inject Sample`) in the bottom 1/3 of the viewport.
- **Minimum Touch Targets**: All interactive elements strictly $\ge 44\times 44\text{px}$.
- **Zero Horizontal Scroll**: Single-column responsive collapse on viewports $<768\text{px}$.

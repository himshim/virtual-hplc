# Validation & Visual Quality Gate Artifacts

This directory contains automated visual screenshots, Playwright test logs, and scientific regression benchmarks for the Virtual Analytical Laboratory.

---

## 📁 Validation Folders & Reports

- **`screenshots/`**: Playwright-captured UI state screenshots for Desktop (1920×1080) and Mobile (390×844).
- **`reports/`**:
  - `educational_verification_report.md`: Verification results for Pre-Run Prediction, Contextual Why Chips, Inline Observations, and Multi-Run Overlay.
  - `scientific_validation_report.md`: USP & Journal of Chromatography A benchmarks ($100\%$ pass rate, average error $< 1.5\%$).

📐 Beer-Lambert Law Derivation

A = -log₁₀(I / I₀) = ε · c · l

Absorbance is directly proportional to concentration ($c$) and optical path length ($l$):

  • A: Absorbance (dimensionless absorbance units, AU)
  • ε: Molar Absorptivity (L · mol⁻¹ · cm⁻¹)
  • c: Analyte concentration (mol · L⁻¹)
  • l: Cuvette optical path length (cm)
